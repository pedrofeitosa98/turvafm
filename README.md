# turvaFM

Este é o repositório oficial do nosso projeto de fã-site para o [Turva](http://turva.com.br/), um servidor old school de Habbo Hotel.
Este projeto está sendo desenvolvido de forma independente e como um hobby/projeto pessoal, então ele pode caminhar mais lento do que o esperado.

## 🧱 Ferramentas e Bibliotecas

- ⚡ Vite
- ⚛️ React
- 🧭 TanStack Router
- 💅 Styled Components
- 🗄️ Supabase
